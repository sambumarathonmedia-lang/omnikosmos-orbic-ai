# OMNIKOSMOS roadmap

## Milestone 1 — Digital proof of concept (current)
- [x] Browser-based orb interface
- [x] Local rule-based demo console
- [x] Simulated system checks and event log
- [x] Exportable report
- [ ] Publish via GitHub Pages
- [ ] Add screenshots and a short demo video

## Milestone 2 — Software architecture
- Separate UI, state, sensor abstractions, event log, and reporting
- Add a clear simulation/live-data indicator
- Add test cases and documented APIs
- Connect a real AI service only after selecting a provider and protecting API credentials on a backend (never place secret keys in public browser code)

## Milestone 3 — Physical body design
- Finalize dimensions after component selection
- Create dimensioned CAD and exploded assembly
- Validate thermal, electrical, structural, and service-access requirements
- Build a non-powered fit-check shell before powered testing

## Milestone 4 — Stationary sensor prototype
- Select a microcontroller or single-board computer
- Add low-voltage environmental sensors and status lighting
- Define safe power, fusing, enclosure ventilation, and emergency shutdown
- Connect readings to the software through a documented local interface

## Milestone 5 — Experimental field research
- Begin with low-energy, measurable experiments and appropriate instruments
- Record methods, calibration, uncertainties, and repeatability
- Compare observations against established electromagnetic theory
- Avoid claiming propulsion or field compression unless demonstrated with controlled measurements

## Long-term speculative goal
Explore whether any physically valid mechanism could support movement through water, air, and space. Dimensional transport is speculative and is not a demonstrated engineering capability. It requires new testable hypotheses and evidence before feasibility can be assessed.
