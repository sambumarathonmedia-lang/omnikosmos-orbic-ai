# Preliminary parts plan (not yet purchased or tested)

This is a selection checklist, not a claim that hardware has been built.

| Subsystem | Candidate approach | Status |
|---|---|---|
| Compute | Existing laptop for initial demo; later choose an appropriate microcontroller/SBC | Not selected |
| Sensors | Temperature/humidity; optional light or distance sensor | Not selected |
| Indicator ring | Low-voltage addressable LED ring or segmented LEDs | Not selected |
| Power | Certified low-voltage USB supply for stationary prototype | Not selected |
| Enclosure | Printed plastic or fabricated shell after CAD and fit checks | Not selected |
| Mount | Stable stand for initial stationary prototype | Not selected |
| Connectivity | USB or local Wi-Fi interface after software design | Not selected |

Before purchase, compare current availability, voltage/current requirements, software support, mechanical dimensions, and safety. No Raspberry Pi, sensor, coil, or other component should be listed as used until it has actually been obtained and tested.
