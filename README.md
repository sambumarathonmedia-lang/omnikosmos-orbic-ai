# OMNIKOSMOS Orbic Intelligence

**An experimental digital prototype and engineering roadmap for a modular spherical intelligent device.**

OMNIKOSMOS explores a long-term concept: a spherical device combining software intelligence, sensors, embedded computing, a modular body, and research into electromagnetic fields and advanced transport.

## Try the digital demo

This repository is designed for GitHub Pages. Once Pages is enabled, open the published site URL in a modern browser. The current demo is a single-page application; it does not require a build step or dependencies.

## Current demo features

- Animated orb interface and status indicators
- Local rule-based reasoning console
- Simulated system checks and event log
- Exportable plain-text demo report
- Responsive layout for phones and computers

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Try the system check, reasoning console, and report export.

## Project status — read carefully

**Software demo only.** The current browser demo is not connected to a live AI model or physical sensors. It does not control hardware, generate propulsion, compress electromagnetic fields, transport matter, or demonstrate dimensional travel. Any sensor-like values in the demo are illustrative/simulated.

The orb illustration and body plan are conceptual. The hardware notes are preliminary design targets, not manufacturing-ready drawings or validated engineering specifications.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish. The URL is usually `https://YOUR-USERNAME.github.io/omnikosmos-orbic-ai/`.
